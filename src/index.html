常问的几条。

会改动我的表格内容吗？

不会。工具只读取单元格的显示文本，不重排、不改格式、不四舍五入，也不合并重复值。所有列原样打印，空单元格就留空。

为什么页数是这个数字？

页数由行高、栏数和可用高度算出来。每一栏能放多少行是确定的：可用高度除以下一行的高度，向下取整。上面的数字就是实际排版结果，不是估算。

一行会不会被拆到两栏？

不会。行是排版的最小单位，装不下就整行挪到下一栏。所以栏底可能会留一点空白，这个空白换的是一行不被腰斩。

表头是每栏一份还是每页一份？

每栏都有一份。第二栏、第三栏顶部都会重新列出列名，散页之后单独拿一栏起来也知道是什么。

页码长什么样？

页脚居中，宋体，格式是「第 3 页 共 81 页」。总页数在排版时就算好了，不依赖打印机。可以在面板里关掉。

数据会被上传吗？

不会。这个页面是一个离线文件，Excel 在你的浏览器里解析，没有服务器，也没有任何网络请求。断网、拔网线都一样能用。

打印对话框要怎么设？

点「打印」会单独开一个只包含纸张的窗口，那个窗口里再点一次打印，浏览器对话框就会出来。边距选「无」，缩放保持 100%，把「页眉和页脚」的勾去掉。纸张选 A4，方向和面板里的设置保持一致。版式已经按 A4 精确排版，浏览器不要再缩放。

只要前几页试样，在「页码范围」里填 1-10 即可。

内网的老浏览器能用吗？

可以。整个页面按 Chrome 83 内核写，不使用更新的 CSS 特性和脚本语法，麒麟、统信、奇安信这类内网浏览器都能跑。数据全程在本机，不依赖任何网络。

支持哪些文件？多工作表呢？

支持 xlsx、xls、csv。一个文件里有多个工作表时，会列出来让你挑一个，不会一次全铺开。

文件在你的浏览器里解析。没有服务器，也没有上传，关掉页面就什么都不剩。
